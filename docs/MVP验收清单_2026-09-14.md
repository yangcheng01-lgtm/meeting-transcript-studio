# 多听工作台 MVP 验收清单

> 版本：2026-09-14
> 项目：AI 声纹识别与纪要梳理（多听工作台）
> 验收目标：导入音频/视频/YouTube/多文件 → 区分 speaker → 人工标人名 → 带时间戳逐字稿 → 选择总结 skill → 生成可审改报告
> 标记说明：P0 = 必须通过才能提交 MVP；P1 = 通过后加分项，作为演示亮点可选

---

## A. 交付链路（P0 主线）

- [x] A-01 支持上传本地音频文件（wav/m4a/mp3 等）
- [x] A-02 支持上传本地视频文件并自动提取音频
- [x] A-03 公开 YouTube 链接支持 5–600 秒截取；60 秒样本已完成 Speaker→英文 ASR→人名→逐字稿→报告
- [x] A-04 支持一次导入多个文件并按顺序拼接成单一时间轴
- [x] A-05 声纹分离（pyannote/speaker-diarization-3.1）能区分多个 Speaker
- [x] A-06 每个 Speaker 有代表发言文本与代表片段，可用于辅助人工标注
- [x] A-07 界面上支持为每个 Speaker 填写人名 / 角色
- [x] A-08 转写采用公司 qwen3-asr（Speaker-aware，继承声纹时间边界）
- [x] A-09 输出带时间戳和人名的逐字稿
- [x] A-10 逐字稿可导出为文档，后续可审改

## B. 会议纪要（P0 主线）

- [x] B-01 可选择 4 个总结 Skill（会议纪要、业务访谈、培训讲解、通用报告）
- [x] B-02 模型设置可配置 API URL / API Key / 模型名（/v1/chat/completions）
- [x] B-03 生成结构化报告：事实 / 共识 / 推断分层
- [x] B-04 报告保留数字口径，不臆造负责人与截止日期
- [x] B-05 输出决策、风险、开放问题、行动项（建议跟进）
- [x] B-06 报告按 Skill 保存为 <项目>__OUT__<报告类型>.md，可人工审改

## C. 声纹与人名标注（P0 主线）

- [x] C-01 声纹模型本地/离线运行（HF 模型已缓存，普通用户无需 HF token）
- [x] C-02 支持 expected_speakers / num_speakers 设定说话人数（提供已知人数入口）
- [x] C-03 每个 Speaker 可试听代表片段声音
- [x] C-04 每人名与角色标注后自动应用到对应时间片段

## D. 稳定性与正确性（P0）

- [x] D-01 中英文公开样本测试通过（AliMeeting 中文、AMI 英文）

- [x] D-04 冒烟测试通过（7 tests passed）
